# design

Пайплайн hi-fi макетов для Figma. SVG генерируется Python-скриптами и заливается в Figma через собственный MCP stdio-клиент figwright, чтобы большая разметка не шла через чат. Концепции A–E сделаны под v1 (7 экранов бэктеста) и ещё не обновлены под v2.

```
python design/concepts/<A..E>/gen.py                              # -> design/concepts/<X>/out/<X>1..7.svg
node design/tools/fw.mjs design/concepts/<X>/push.json   # залить экраны в Figma
```

Figma-файл «ПАК», страница «Концепции»: 5 концепций × 7 экранов. Бесплатный тариф — максимум 3 страницы, новые экраны добавлять секциями или фреймами.

- Для `fw.mjs` должен быть открыт плагин Figwright в Figma. Джоб `{"screen": {"frame", "svgFile", "name"}}` очищает фрейм, подгоняет размер под SVG и импортирует его, поэтому повторный запуск безопасно заменяет экран. Пути `svgFile` — относительно json. Путь к figwright — переменная `FIGWRIGHT_MCP` (по умолчанию — путь из npx-кэша Дениса в `fw.mjs`). Остальные json в `tools/` — разовые джобы, которыми создавались фреймы и секции (`frames.json`, `sections.json`, `frame_ids.txt`).
- `shared/BRIEF.md` — бриф: 7 экранов и обязательное содержимое каждого, стили концепций A–E (Лаборатория / Терминал / Мастер / Исследование / Дашборд), токены Taiga UI, правила копирайтинга. Читать перед правкой любого экрана.
- `shared/data.py` — единственный источник фейковых данных: стратегия, метрики, ряды, прогоны. Цифры не выдумывать, брать отсюда, чтобы концепции были согласованы (например, наивный +84,2 % → честный +31,6 %).
- `shared/svg.py` — мини-библиотека отрисовки (`Svg`, `text/para/wrap/truncate/measure`, `series/candles/bars`, `icon`). Ширина текста меряется через PIL по шрифтам в `shared/fonts`. Текст, который может не влезть, пропускать через `wrap`/`truncate`.
- Скрипты подключают `shared/` относительным путём от своего файла; запускать из корня `home`.
- `prototype/E/` — кликабельный HTML-прототип v2.

Ограничения импорта SVG в Figma: только Manrope и JetBrains Mono (serif не рендерится); начертание 400 становится Regular, 700 — Bold, остальные округляются; letter-spacing теряется. Работают `text-anchor`, `tspan`, градиенты, `clip-path`, `dasharray`.

Проверка результата — `mcp__figwright__get_screenshot` по id фрейма. Он падает по таймауту, если плагин делят несколько агентов. Не трогать узлы вне своих фреймов, не использовать `navigate_to_page`/`use_file`.
