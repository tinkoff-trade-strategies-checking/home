# Бриф: пять концепций фронта «Честная проверка стратегий»

Учебный проект: событийная платформа бэктеста учебных стратегий на данных MOEX без «заглядывания в будущее», с учётом комиссий, ликвидности и задержек. Фронт на Angular + **Taiga UI**. Аудитория: студенты-исследователи и проверяющие на защите. Главное, что продукт должен доказать на показе: ручные примеры сходятся, исследование воспроизводится, проверка ловит чтение будущего, издержки меняют слишком оптимистичный результат.

Название продукта в шапке — **«Честная проверка стратегий»** (дословно). Язык интерфейса — русский. Desktop 1440 px шириной.

## Общие правила

- **Данные только из `design/shared/data.py`**: одна стратегия, одни цифры, одни ряды. Ничего не выдумывайте поверх (кроме мелкой интерфейсной копии).
- **Рисование только через `design/shared/svg.py`**: `Svg`, `text/para/wrap/truncate/measure`, `series/area_down/candles/bars`, `icon`. Любой текст, который может не влезть, проходит через `wrap`/`truncate` по реальной ширине.
- Ограничения импорта в Figma: только Manrope и JetBrains Mono, только начертания 400 и 700, letter-spacing не работает, serif не отрисовывается.
- Токены Taiga UI (из исходников, `taiga-palette.less` / `taiga-variables.less`):
  - светлая тема: base `#FFFFFF`, base-alt `#F6F6F6`, text-primary `#1B1F3B`, secondary `rgba(27,31,59,.65)`, tertiary `rgba(27,31,59,.4)`, action `#4C66C3`, accent-1 `#526ED3`, positive text `#008764`, negative text `#EB1700`, status positive `#4AC99B`, warning `#FFC700`, info `#70B6F6`, border `rgba(0,0,0,.1)`;
  - тёмная тема: base `#222`, base-alt `#333`, elevation `#292929`, text `#FFF / .72 / .6`, action `#6788FF`, positive `#44C596`, negative `#FF4D4D`, border `rgba(255,255,255,.14)`;
  - радиусы: xs 4, s 8, m 10, l 12, xl 24; высоты контролов: xs 24, s 32, m 44, l 56;
  - типографика: h1 50/56, h2 44/48, h3 36/40, h4 28/32, h5 24/28, h6 20/24, body-l 17/28, body-m 16/24, body-s 14/20, body-xs 12/16, ui-m 16/20, ui-s 14/16, ui-xs 12/15. Все заголовки bold.
  - Концепция может сдвигать палитру (у каждой свой стиль), но компоненты узнаваемы как Taiga: кнопки высотой 32/44, поля ввода с подписью внутри, бейджи, табы, island-карточки. Жёлтый `#FFDD2D` с чёрным текстом — общая нить всех концепций: главное действие («Запустить прогон») и активные состояния.
- Копирайтинг: sentence case, активный залог, кнопка называет действие («Запустить прогон», не «Отправить»). Без ALL CAPS-подписей, без надзаголовков над каждым блоком, без строк через « · », без «→» в конце кнопок и ссылок. Ошибки объясняют, что случилось и как исправить, без извинений.
- Нумерация (01/02) — только там, где реально последовательность (шаги мастера, главы отчёта, окна walk-forward).
- Везде, где показан результат, — дисклеймер из `data.DISCLAIMER` (мелко, но присутствует).

## Семь экранов и что на каждом обязано быть

| # | Экран | Обязательное содержимое (из принятых решений HANDOFF §4) |
|---|---|---|
| 1 | Датасеты | список неизменяемых снапшотов (`DATASETS`): источник, тикеры, интервал, период, дата получения, хэш, версия схемы, где используется; статус «после MVP» у генератора; карточка выбранного снапшота с полями и моментом доступности (`DATASET_FIELDS`), торговый календарь с разрывом 28.02–23.03.2022; действие «Загрузить новый снапшот» (MOEX ISS) |
| 2 | Стратегия | редактор DSL в стиле Pine (`DSL_MAIN`), статанализ «чтения будущего» с тремя уровнями (`LOOKAHEAD_CHECKS`: OK / подозрительно / ошибка — прогон невалиден), список стратегий (`STRATEGIES`) |
| 3 | Настройка прогона | датасет, период, капитал, издержки (`RUN_CONFIG`: комиссия, биржевой сбор, спред, проскальзывание, лимит ликвидности, задержка исполнения по open t+1), правило остановки, стресс-сценарий (`STRESS_PRESETS`, включая «Свой сценарий» с гэпом/волатильностью/объёмом/проскальзыванием), режим walk-forward, «наивный и честный прогон вместе», seed; кнопка «Запустить прогон» |
| 4 | Отчёт прогона | кривая капитала (`EQUITY_HONEST`, сравнение с `EQUITY_NAIVE` и `EQUITY_IMOEX`), underwater-просадка (`drawdown`), отметки стресс-событий (март 2020, 24.02.2022 + разрыв торгов), свечи SBER с маркерами сделок (`candles`, `TRADE_MARKERS`: покупка, частичное, продажа, отказ); метрики `RESULT_HONEST` (total/CAGR/gross/net, макс. просадка и длительность, волатильность, Sharpe, Sortino, оборот, сделки, win rate, частичные/отказы, HHI, крупнейшая позиция, бенчмарк), издержки по видам (`DELTA_BREAKDOWN`, `COSTS_TOTAL`), warning'и (`FLAGS`), метаданные воспроизводимости (`REPRO`) и кнопка «Воспроизвести» |
| 5 | Сравнение | «наивный vs честный» с разложением разницы 84,2 → 31,6 по вкладам (`DELTA_BREAKDOWN`) — это ключевой момент защиты; таблица нескольких стратегий (`COMPARISON`) с флагами: издержки > 50 % прибыли, издержки меняют знак результата, наивный Sharpe > 3; наложение кривых стратегий и IMOEX |
| 6 | Walk-forward | схема окон 1 год подбор / 3 мес. проверка / сдвиг 3 мес. (`WALK_FORWARD`, 20 окон), доходность in-sample vs out-of-sample по окнам, выбранные параметры по окнам, сводка `WF_SUMMARY` (деградация, доля прибыльных окон, стабильность параметров) |
| 7 | История прогонов | список `RUNS` со статусами (`STATUS_LABEL`: валиден / с пометкой / невалиден, причина `INVALID_REASON`), режимом, датасетом, автором; фильтры; действия «Воспроизвести», «Сравнить выбранные» |

Интерактива во время прогона нет: изменение параметров = новый прогон. Шорты, маржа, новости — не делаем (можно показать как недоступное «после MVP», но не обязательно).

## Пять концепций

Каждая концепция — свой UX и свой визуальный стиль. Ниже — направление, которое агент развивает. Одна запоминающаяся деталь на концепцию, остальное спокойно и дисциплинированно.

### A. Лаборатория — IDE, код в центре
- **Идея**: исследователь пишет стратегию как код; всё остальное — панели вокруг редактора.
- **Палитра**: чернильно-синяя тёмная (не нейтрально-чёрная): base `#0E1726`, панели `#132036`, поверхности `#1A2A44`, линии `#24365A`, текст `#E6ECF5` / `#8DA0BC` / `#5D7091`. Подсветка синтаксиса: ключевые слова `#7FB4FF`, функции `#E6C07B`, числа `#F08D6E`, строки `#9AD4A0`, комментарии `#5D7091`. Статусы: positive `#44C596`, negative `#FF4D4D`, warning `#FFC700`. Жёлтый `#FFDD2D` — кнопка запуска и курсор «горизонта знания».
- **Шрифты**: JetBrains Mono доминирует (код, числа, таблицы, метрики), Manrope — хром интерфейса (меню, кнопки, заголовки панелей).
- **Раскладка**: activity bar 48 px слева (иконки разделов), explorer 260 px (дерево: Датасеты / Стратегии / Прогоны), центр — вкладки и редактор/контент, справа инспектор 320–340 px, снизу панель 200–220 px с вкладками «Проблемы / Консоль / Сделки», статус-бар 24 px (датасет + хэш, seed, версия движка, статус проверки). Оболочка IDE одинакова на всех 7 экранах, меняется содержимое центра/инспектора.
- **Запоминающееся**: колонка «доступность» в гаттере редактора — у каждой строки чип момента доступности данных (`t`, `t`, `t+1`); строка с `close[+1]` подчёркнута красной волной, рядом inline-сообщение. Это и есть «защита от будущего», видимая прямо в коде.

### B. Терминал — графики в центре
- **Идея**: торговый терминал, где прогон «проигрывается» на графиках; стратегия собирается формой-конструктором, DSL виден как результат.
- **Палитра**: нейтральный графит (отличие от A — никакой синевы): base `#15171C`, панели `#1C1F26`, поверхности `#242833`, сетка `#2C313C`, текст `#E8EAED` / `#9AA0AA` / `#666C78`. Свечи: рост `#44C596`, падение `#FF4D4D`. Выделение `#70B6F6`. Жёлтый — запуск и «линия знания».
- **Шрифты**: Manrope везде; крупные bold-числа; JetBrains Mono только для DSL-превью и тикерной ленты.
- **Раскладка**: верхняя панель 48 px + тикерная лента ключевых метрик прогона; слева watchlist 240 px (тикеры вселенной со спарклайнами); центр — тайлинг из 2–4 панелей с графиками (свечи, капитал, просадка, объём); справа лента событий/сделок 300 px; снизу таймлайн-скраббер всего периода с отметками стресс-событий.
- **Запоминающееся**: «линия знания» — вертикальная жёлтая линия на графике свечей: справа от неё данные заштрихованы и подписаны «будущее скрыто от стратегии». Стратегия видит только левую часть.

### C. Мастер — светлый, обучающий, пошаговый
- **Идея**: исследование проходится по шагам, каждое понятие объяснено простым языком. Для студента, который делает первый бэктест.
- **Палитра**: светлая Taiga: base `#FFFFFF`, фон `#F4F5F7`, текст `#1B1F3B` / `#6B6E85` / `#A3A5B5`, линии `#E3E4EA`; жёлтый `#FFDD2D` с чёрным текстом — основные кнопки; мягкий жёлтый `#FFF4C2` — фон пояснений; positive `#008764`, negative `#EB1700`, info `#4C66C3`.
- **Шрифты**: только Manrope, крупнее обычного: заголовки 32/40 bold, текст 16/24.
- **Раскладка**: шапка с названием и вкладками «Новое исследование / Мои исследования»; горизонтальный степпер из 5 шагов (Данные, Стратегия, Издержки и риски, Проверка, Результат — здесь нумерация оправдана); основная колонка ~760 px + справа панель «Почему это важно» ~360 px; липкий футер «Назад / Далее: <название шага>». Экраны 1–4 — шаги мастера (Настройка = «Издержки и риски»), Отчёт — шаг «Результат»; Сравнение и Walk-forward — вкладки результата; История — «Мои исследования».
- **Запоминающееся**: каждая строка DSL сопровождается переводом на человеческий язык («Когда быстрая средняя пересекает медленную снизу вверх — купить на 20 % капитала»), каждая метрика — однострочным объяснением; большой «до/после»: без издержек +84,2 % → с издержками +31,6 %.

### D. Исследование — длинный отчёт-лонгрид
- **Идея**: исследование как научный отчёт, который читают сверху вниз и показывают на защите. Каждый экран — глава одного документа.
- **Палитра**: холодная бумага (не кремовая): фон `#EDF0F4`, лист `#FFFFFF`, чернила `#14213D`, вторичный `#5C6B80`, линии `#D5DAE1`; жёлтый `#FFDD2D` как маркер-выделитель под ключевыми числами и выводами (прямоугольник под текстом); negative `#C8372D`, positive `#0F8A5F`, нейтральная серия `#9AA6B8`.
- **Шрифты**: только Manrope (serif недоступен) — характер через масштаб: выводы-заголовки 40–56 bold, крупные числа 64–72 bold, текст 17/28 (body-l); JetBrains Mono для ячеек с кодом.
- **Раскладка**: слева липкое оглавление 240 px (главы 1–7 = экраны; нумерация оправдана); центральная колонка текста ~720 px, графики шире ~1000 px; справа на полях sidenotes с происхождением данных (снапшот, хэш, seed). Кадры выше 900 px — это лонгрид (1440 × 1600–2600).
- **Запоминающееся**: заголовок главы — это вывод, а не тема («Издержки и задержка съели 62 % прибыли»), ключевые числа подчёркнуты жёлтым маркером.

### E. Дашборд — сайдбар, таблицы, плотная операционная консоль
- **Идея**: рабочее место команды: всё видно таблицами и сводками, быстрый переход между сущностями.
- **Палитра**: светлая: сайдбар `#1B1F3B` с белым текстом, фон `#F2F3F5`, поверхности `#FFFFFF` с бордером `rgba(0,0,0,.1)` без теней, акцент Taiga `#526ED3` для ссылок и выделения, жёлтый только на главной кнопке; статусные бейджи: валиден `#4AC99B`, с пометкой `#FFC700`, невалиден `#FF291A` (фон бейджа — 12–16 % заливки, текст насыщенный).
- **Шрифты**: Manrope, компактно: таблицы 14/20, заголовки разделов 20/24, KPI-числа 28/32.
- **Раскладка**: сайдбар 248 px (проект, навигация по 7 разделам, внизу пользователь); верхняя панель с хлебными крошками, поиском и «Новый прогон»; контент — сетка из панелей разного веса (не одинаковые карточки!), таблицы с сортировкой, графики в панелях. Иерархия радиусов: панели 12, контролы 10, бейджи 8.
- **Запоминающееся**: «светофор честности» — сегментированная полоска из трёх частей (Данные / Будущее / Издержки) у каждого прогона: в таблице истории, в шапке отчёта, в сравнении.

## Пайплайн

1. Генератор концепции: `design/concepts/<буква>/gen.py` → пишет `design/concepts/<буква>/out/<буква><n>.svg` (n = 1…7). Импорт: `sys.path.insert(0, r"C:\D\ПАК\design\shared")`, затем `from svg import *` и `import data as D`.
2. Загрузка в Figma: создать `design/concepts/<буква>/push.json` вида `[{"screen": {"frame": "<id>", "svgFile": "out/A1.svg", "name": "A1 Датасеты"}}, ...]` и выполнить `node C:/D/ПАК/design/tools/fw.mjs design/concepts/<буква>/push.json` (пути svgFile — относительно json). Команда очищает фрейм, подгоняет его под размер SVG и импортирует. Повторный запуск безопасно заменяет экран.
3. Проверка: инструмент MCP `mcp__figwright__get_screenshot` с `nodeIds: ["<id фрейма>"]` (схему загрузить через ToolSearch `select:mcp__figwright__get_screenshot`). Смотреть на переполнение текста, наложения, читаемость, контраст.
4. **Запрещено**: `navigate_to_page`, `get_document`, `get_selection`, `use_file`, любые операции вне своих 7 фреймов, удаление чужих узлов. Параллельно работают ещё 4 агента в том же файле.
